# littllelearning

Die Website liegt zentral im Verzeichnis `website/`.

## Einstieg

- Öffne `website/index.html` im Browser.
- Styles liegen unter `website/css/`.
- JavaScript und Inhalte liegen unter `website/js/main.js`.

## Hinweis

Dateien im Repository-Root enthalten keine alternative Website-Struktur mehr.
